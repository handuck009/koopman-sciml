01

The project

Start small. Understand the operator.
Then test what carries over.

The goal is to study how lifted linear models describe nonlinear dynamics, and where those approximations fail. The planned progression is DMD, EDMD, then continuous-time generator identification.

For now, the code generates two spatial patterns with damped sinusoidal coefficients. It is a synthetic-data starter; DMD fitting and prediction benchmarks are still to come.

Research scope The intended spacecraft benchmark is simulated torque-free asymmetric rigid-body rotation. No hardware, in-orbit, or control results are claimed.

03

Try the starter

One script. A visible starting point.

With Python 3.11+ installed, open a terminal in the project directory. A virtual environment is recommended; setup details are in the repository README.

TERMINAL
python -m pip install -r requirements.txt
python 01_exact_dmd_numpy.py

Opens a plot of the synthetic field. The starter currently generates data only, despite the DMD filename. For a headless preview, run python scripts/export_preview.py.
